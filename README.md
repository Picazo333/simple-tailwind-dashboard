# Simple Tailwind Dashboard

Responsive influencer analytics dashboard built for the 4Geeks Academy Tailwind assignment.

## Stack

- Semantic HTML
- Tailwind CSS v4 via the official browser CDN
- No JavaScript framework
- Mobile-first responsive layout

## Dashboard structure

- **Top:** four KPI cards
- **Insight layer:** executive summary of the strongest business signals
- **Middle:** four performance-driver modules, including a conversion funnel
- **Bottom:** operational product details and insight cards

The page adapts across phone, tablet and desktop layouts using Tailwind breakpoint utilities. Mobile product detail is presented as readable cards and switches to a full table at tablet/desktop sizes.

## Quality pass

Beyond the assignment minimum, the final version includes:

- skip-to-content accessibility;
- visible keyboard focus states;
- coherent revenue/commission/funnel arithmetic;
- responsive runtime verification at phone, tablet and desktop viewports;
- a clean final axe-core accessibility audit with 0 violations.
