# Simple Tailwind Dashboard

Responsive influencer analytics dashboard built for the 4Geeks Academy Tailwind assignment.

## Stack

- Semantic HTML
- Tailwind CSS v4 via the official browser CDN
- No JavaScript framework
- Mobile-first responsive layout

## Dashboard structure

- **Top:** four KPI cards
- **Middle:** three performance-driver modules
- **Bottom:** operational product details and insight cards

The page adapts across phone, tablet and desktop layouts using Tailwind breakpoint utilities.
